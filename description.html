LCARS Science Station — Star Trek-inspired system telemetry dashboard for Linux

A full-screen, real-time system monitoring dashboard with an authentic LCARS aesthetic (Strange New Worlds style). Runs on any Wayland or X11 compositor: Mango, Hyprland, Sway, KDE, GNOME.

Live metrics

  • CPU — total load, load average, peak frequency, per-core usage, load history
  • Memory — RAM, swap, GPU load, VRAM usage
  • Thermals — CPU, GPU (edge/junction/mem), NVMe, motherboard sensors
  • Network — throughput, totals, interface, IP
  • Storage — partitions, btrfs device errors, snapshot vault
  • Processes — top consumers, power matrix (CPU/GPU watts), node specs

What you get

  • Ready-to-run Electron app + install.sh (Arch/CachyOS, Debian/Ubuntu, Fedora)
  • Window manager adapters: Mango, Hyprland, Sway
  • Landscape and portrait layouts (automatic breakpoints)
  • config.json: refresh rate, hostname override, health-check pings, custom launcher command
  • Desktop entry + icon for application menus
  • README + changelog, all in English

100% local. Zero cloud. No account. No telemetry. Ever.

Everything runs on your machine. Your data never leaves it.
